# Datasets

Downloaded or research datasets belong here. The paper identifies the primary
source as the Sun et al. figshare archive, record `14888121`, containing the
ultralow-temperature refrigeration data used by the provided Colab workflow.

The cleaned project copy is kept once, canonically, at
`ai_worker/data/Test1_TempCO2O2.csv` because it is consumed by the model
trainer and deterministic event generator. It is not duplicated here.

This dataset is not a GARDASIL 9 pharmacy-refrigerator dataset and must not be
used to make clinical, compliance, release, quarantine, or discard decisions.
Any archive, notebook export, or future dataset downloaded from Drive should
be placed in this folder, with its source URL and field notes recorded here.

The project archive downloaded from Drive is
`14888121-20260708T173347Z-3-001.zip`.
