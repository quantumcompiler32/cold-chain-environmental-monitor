# Research

Put research papers, source notes, and other supporting research files here.
Research is documentation only and is not imported by the live MQTT,
PostgreSQL, or dashboard processes.

The main project paper is
`vaccine_storage_monitoring_report_final_clinical_protocol.docx`. It documents
the GARDASIL 9 case study, the supplied Colab analysis, the public ultralow-
temperature dataset, the sensor plan, and the limits of the educational
prototype. URLs cited by the project are listed in `research_urls.doc`.

Additional research materials downloaded from the project Drive folder include
the ultralow-temperature dataset paper PDF, the Local Student Environmental
Sensor Research Project document, and `ML_Questions.docx`.
