# Keep live sources canonical and use shared vault branches

The live project directory remains authoritative for original files, while one Obsidian vault provides curated notes, provenance, navigation, project management, and decision views. The vault uses seven shared branches across all projects and distinguishes projects with metadata and project index pages. This avoids scattering work across separate vault structures or duplicating canonical knowledge while keeping ByteSmart, Bitwise, shared infrastructure, and future projects easy to browse.

## Consequences

- Every imported or connected artifact needs a source record.
- Canonical notes promote useful, durable information instead of copying every source verbatim.
- Automation must preserve originals and flag ambiguity for review.
- Users can browse by branch or project without maintaining duplicate notes.
