# IoT Simulation Obsidian Project

This folder is ready to drop into your Obsidian vault:

```text
Your Obsidian Vault/Internship/IoT_Simulation_Obsidian_Final_Updated/
```

Open **`00 - IoT Simulation Environment Setup.md`** first.

## Fast installation on macOS

From Terminal, while inside this folder:

```bash
bash scripts/install_iot_shortcuts.sh
source ~/.zshrc
iot setup
iot help
```

Both commands work:

```bash
iot help
io help
```

> Do not run `source ~/install_iot_shortcuts.sh`. The installer is inside this project under `scripts/`. After installation, reload the shell with `source ~/.zshrc`.
