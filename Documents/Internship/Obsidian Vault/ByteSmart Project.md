# ByteSmart Project

ByteSmart is the internship project context used for the cold-chain and environmental-monitoring work. The project evolved from learning data handling and visualization into a sensor/data pipeline with exploratory analysis and carefully bounded machine-learning experiments.

## Current shape

- Public refrigeration/cold-chain datasets are used for analysis.
- Arduino Uno R4 Minima, DHT22, and BMP280 hardware are planned or used for sensor experimentation.
- CSV readings are transformed into JSON events.
- MQTT carries events to subscribers and a PostgreSQL listener.
- ML work includes linear regression, logistic regression, and K-Means, with explicit limits on what each model can claim.
- The project includes a safety-conscious paper and a facility-outreach plan.
